## ndl_get_carbon_removal_facilities

**Carbon removal facilities (CORC)**. List Puro.earth carbon removal facilities: location, methodology, owner, auditor. Read-only. Calls Nasdaq Data Link.

Every facility that has issued CORCs, from Nasdaq's Carbon Removal Data-CORC (free, refreshed daily), one row per durability category, with the latest audit date and audited period. Its facility_id or name feeds `facilities` in ndl_get_carbon_removal_data.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `facilities` | string or list of strings | none | Facility IDs or exact facility names; one or a list. |
| `country` | string | none | Country of the facility, e.g. 'Finland' or 'USA'. |
| `region` | string | none | Continent of the facility. One of: `Africa`, `Asia`, `Europe`, `North America`, `Oceania`, `South America`. |
| `methodology` | string | none | Puro.earth methodology. One of: `Biochar`, `Carbonated Materials`, `Enhanced Rock Weathering`, `Geologically stored carbon`, `Soil Amendment`, `Terrestrial Storage of Biomass`, `Wooden Building Elements`. |
| `durability_category` | string | none | Durability class. One of: `CORC`, `CORC 20+`, `CORC 100+`, `CORC 1000+`. |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |

## ndl_get_carbon_removal_data

**Carbon removal volumes and trades**. Get Puro.earth carbon removal (CORC) volumes, retirements, transactions, prices. Read-only. Calls Nasdaq Data Link.

Puro.earth registry since 2019 (one CORC = one tonne of CO2 removed). Free, refreshed daily, newest first, except reference_prices (subscription).

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `dataset` | string | required | Table to read. One of: `facility_volumes`, `methodology_volumes`, `retirements`, `transactions`, `registry_view`, `reference_prices`. |
| `facilities` | string or list of strings | none | Facility IDs or exact facility names; one or a list. |
| `methodology` | string | none | Puro.earth methodology. One of: `Biochar`, `Carbonated Materials`, `Enhanced Rock Weathering`, `Geologically stored carbon`, `Soil Amendment`, `Terrestrial Storage of Biomass`, `Wooden Building Elements`. |
| `durability_category` | string | none | Durability class. One of: `CORC`, `CORC 20+`, `CORC 100+`, `CORC 1000+`. |
| `transaction_type` | string | none | Withdrawal: registry_view only. One of: `Issuance`, `Transfer`, `Retirement`, `Withdrawal`. |
| `account_holder` | string | none | Part of a beneficiary or receiver name. |
| `retirement_location` | string | none | Beneficiary's country or continent. |
| `start_date` | string | none | Earliest period: YYYY or YYYY-MM-DD. |
| `end_date` | string | none | Latest period: YYYY or YYYY-MM-DD. |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |
