## ndl_search_mutual_funds

**Search mutual funds**. Find mutual funds and their share classes by ticker, name, CUSIP or id. Read-only. Calls Nasdaq Data Link.

Searches the Nasdaq Fund Network fund master (NFN/MFRFM) and share-class master (NFN/MFRSM). A ticker, CUSIP or id is an exact lookup; otherwise a fund matches when every word of the query appears in its fund or share-class name, ignoring case. Each fund comes with fund_id, name and type, and its share classes with security_id, ticker and inception date.

The full tables cover US open-end and closed-end funds; a free key sees a fixed sample of about 30 funds. The tickers and ids feed ndl_get_mutual_fund_report.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `query` | string | `""` | A share-class ticker ('LIBAX'), words of a fund or share-class name ('columbia bond'), a CUSIP, or a fund_id/security_id UUID. Empty lists funds in name order. |
| `limit` | integer (1-50) | `10` | Maximum funds to return (default 10). |

## ndl_get_mutual_fund_report

**Get a mutual fund report**. Read a Nasdaq Fund Network mutual fund report (NFN/MFR*). Read-only. Calls Nasdaq Data Link.

Funds are exact tickers or ids from ndl_search_mutual_funds. Rows are newest first; holdings largest first, at the latest N-PORT date. A free key gets a different fixed sample per table, so some reports are empty for a fund; flows and monthly_returns need a subscription.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `report` | string | required | fund_info: objective, assets; fees: expense ratios, loads; pricing: NAV, returns vs benchmark; performance: alpha, beta, Sharpe; holdings, top_holdings: N-PORT positions; flows: sales, redemptions. One of: `fund_master`, `fund_info`, `share_classes`, `fees`, `pricing`, `performance`, `top_holdings`, `holdings`, `managers`, `flows`, `monthly_returns`, `benchmarks`. |
| `tickers` | string or list of strings | none | Share-class tickers (nav_symbol), not names: 'LIBAX'. |
| `security_ids` | string or list of strings | none | Share-class UUID(s). |
| `fund_ids` | string or list of strings | none | Fund UUID(s). |
| `benchmark_ids` | string or list of strings | none | Benchmark UUID(s). |
| `start_date` | string | none | Earliest date to include, YYYY-MM-DD. |
| `end_date` | string | none | Latest date to include, YYYY-MM-DD. |
| `columns` | string or list of strings | none | Columns to return, or 'all'. |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |
