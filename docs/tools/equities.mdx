## ndl_search_tickers

**Search US stock and fund tickers**. Find US stocks and ETFs by ticker or company name (free Sharadar ticker master). Read-only. Calls Nasdaq Data Link.

SHARADAR/TICKERS, free and current, delisted securities included. `tickers` gives one row per security: exchange, sector, industry, market-cap scale, date ranges and `tables` (the Sharadar tables that carry it). `query` matches a ticker exactly or names containing every query word, over ticker lists downloaded once (about 4 calls) and cached for 24 hours.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `tickers` | string or list of strings | none | Optional ticker or list of tickers to restrict the results to. |
| `query` | string | none | Company or fund name words, e.g. 'nvidia'. |
| `security_type` | string | `"all"` | stock: SEP/SF1; fund: ETFs, CEFs, ETNs (SFP); all: both. One of: `all`, `stock`, `fund`. |
| `exchange` | string | none | Exact exchange, e.g. NASDAQ, NYSE, NYSEARCA. |
| `category` | string | none | Category substring, e.g. 'ADR' or 'ETF'. |
| `sector` | string | none | Sector substring, e.g. 'Technology'. |
| `include_delisted` | boolean | `false` | Include delisted securities in searches. |
| `limit` | integer (1-200) | `20` | Maximum securities from a search. |

### Tables

| Table | Name | Free key | Last refreshed by Nasdaq |
|---|---|---|---|
| [`SHARADAR/TICKERS`](https://data.nasdaq.com/databases/SFP) | US ticker master (Sharadar) | Free | 2026-10-03 |

## ndl_get_fundamentals

**Get company fundamentals**. Get income statement, balance sheet, cash flow and ratio data from Sharadar SF1. Read-only. Calls Nasdaq Data Link.

About 105 fields per US company and period, newest first (definitions: ndl_search_financial_metrics). Free key: a fixed sample (about 30 large US companies, a few years).

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `tickers` | string or list of strings | required | One ticker or a list of tickers ('AAPL', ['AAPL', 'MSFT'] or 'AAPL,MSFT'). |
| `dimension` | string | `"MRY"` | MR*: restated; AR*: as first reported. Y annual, Q quarterly, T trailing 12 months. One of: `MRY`, `MRQ`, `MRT`, `ARY`, `ARQ`, `ART`. |
| `start_date` | string | none | Earliest period: YYYY or YYYY-MM-DD. |
| `end_date` | string | none | Latest period: YYYY or YYYY-MM-DD. |
| `date_field` | string | `"calendardate"` | Date the range filters (datekey: filing date for AR*). One of: `calendardate`, `datekey`, `reportperiod`. |
| `metrics` | string or list of strings | none | SF1 field codes to add to the date keys, e.g. ['revenue', 'fcf'], or 'all' (default: 30 common fields). |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |

### Tables

## ndl_search_financial_metrics

**Search Sharadar field definitions**. Search the Sharadar data dictionary for field codes, titles, units and meaning. Read-only. Calls Nasdaq Data Link.

Reads SHARADAR/INDICATORS (free, full) for one table: each field's code (the column name to pass as `metrics` to ndl_get_fundamentals), title, unit type, whether it is filterable, and its definition; an empty query lists them all. Also decodes the 8-K event codes (EVENTCODES) and corporate action types (ACTIONTYPES).

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `query` | string | `""` | Words in field codes, titles or definitions. |
| `table` | string | `"SF1"` | Table whose fields to list (EVENTCODES, ACTIONTYPES: codes). One of: `SF1`, `DAILY`, `SEP`, `SFP`, `METRICS`, `TICKERS`, `ACTIONS`, `ACTIONTYPES`, `SP500`, `EVENTS`, `EVENTCODES`, `SF2`, `SF3`, `SF3A`, `SF3B`, `INDICATORS`, `TABLE-DESCRIPTIONS`. |
| `limit` | integer (1-200) | `30` | Maximum fields to return. |

### Tables

| Table | Name | Free key | Last refreshed by Nasdaq |
|---|---|---|---|
| [`SHARADAR/INDICATORS`](https://data.nasdaq.com/databases/SFP) | Column dictionary (Sharadar) | Free | 2026-09-25 |

## ndl_get_stock_prices

**Get daily stock or fund prices**. Get daily open/high/low/close/volume for US stocks (SEP) or funds and ETFs (SFP). Read-only. Calls Nasdaq Data Link.

`close` is split-adjusted, `closeadj` also adjusts for dividends and spinoffs, and `closeunadj` is as traded. Newest first; without dates, the latest rows. A free key gets a fixed sample of large stocks and funds over a past date window. ndl_search_tickers tells whether a symbol is a stock or a fund.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `tickers` | string or list of strings | required | One ticker or a list of tickers ('AAPL', ['AAPL', 'MSFT'] or 'AAPL,MSFT'). |
| `security_type` | string | `"stock"` | stock: SEP (stocks, ADRs); fund: SFP (ETFs, CEFs, ETNs). One of: `stock`, `fund`. |
| `start_date` | string | none | Earliest date to include, YYYY-MM-DD. |
| `end_date` | string | none | Latest date to include, YYYY-MM-DD. |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |

### Tables

| Table | Name | Free key | Last refreshed by Nasdaq |
|---|---|---|---|
| [`SHARADAR/SEP`](https://data.nasdaq.com/databases/SFA) | US stock prices (Sharadar) | Sample | 2026-10-03 |
| [`SHARADAR/SFP`](https://data.nasdaq.com/databases/SFP) | US fund prices (Sharadar) | Sample | 2026-10-03 |
