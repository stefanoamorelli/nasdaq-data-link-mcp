## ndl_get_crypto_prices

**Get Bitfinex crypto prices**. Daily Bitfinex crypto prices (last, bid, ask, mid, high, low, volume) by pair. Read-only. Calls Nasdaq Data Link.

Reads QDL/BITFINEX, free with any API key: one row per pair and day, newest first. High, low and volume cover 24 hours; volume is in the base asset and prices in the second one (BTCUSD in US dollars, ETHBTC in bitcoin). With several pairs `limit` is shared between them.

Nasdaq has not updated the table since 2026-06-22. 44 pairs have rows up to then (BTCUSD since 2014); about 850 pairs that left the feed earlier stay readable (e.g. SOLUSD). Bitcoin network data is in ndl_get_blockchain_metrics.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `pairs` | string or list of strings | required | Up to 20 Bitfinex pair codes, e.g. 'BTCUSD' or ['ETHUSD', 'ETHBTC']; case and separators ('btc/usd') are ignored. Bitfinex writes USDT as UST and USDC as UDC. |
| `start_date` | string | none | Earliest date to include, YYYY-MM-DD. |
| `end_date` | string | none | Latest date to include, YYYY-MM-DD. |
| `fields` | list of strings | none | Columns to return besides code and date (default: all). One of: `high`, `low`, `mid`, `last`, `bid`, `ask`, `volume`. |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |

## ndl_get_blockchain_metrics

**Get Bitcoin blockchain metrics**. Daily Bitcoin network metrics: price, hash rate, difficulty, fees, transactions. Read-only. Calls Nasdaq Data Link.

Reads QDL/BCHAIN (blockchain.com data), free with any API key: one value per metric and day since January 2009, as rows of (code, date, value), newest first; the result's `metrics` field gives each code's label and unit. With several metrics `limit` is shared between them, so metrics='all' with limit=23 returns the latest value of each.

Nasdaq has not updated the table since 2026-06-23, and some days are missing (up to 1 in 5 since mid-2025). Ten discontinued codes (e.g. BCDDE) stay readable. Exchange prices of other coins are in ndl_get_crypto_prices.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `metrics` | string or list of strings | required | QDL/BCHAIN metric codes such as MKPRU (price) or ['HRATE', 'DIFF']; 'all' selects the 23 metrics that ran until June 2026. |
| `start_date` | string | none | Earliest date to include, YYYY-MM-DD. |
| `end_date` | string | none | Latest date to include, YYYY-MM-DD. |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |

### Tables

| Table | Name | Free key | Last refreshed by Nasdaq |
|---|---|---|---|
| `QDL/BCHAIN` | Bitcoin network metrics | Free | 2026-06-23 |
