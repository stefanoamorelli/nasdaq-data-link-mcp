## ndl_get_imf_weo_data

**Get IMF World Economic Outlook data**. Get IMF World Economic Outlook annual data (GDP, growth, inflation, debt). Read-only. Calls Nasdaq Data Link.

QDL/ODA (free): the April 2023 WEO, 1980-2028, for 196 economies, 13 IMF groups and commodity prices (under WORLD). `projected` flags years after 2022. ndl_get_world_bank_data has World Bank actuals.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `indicators` | string or list of strings | none | WEO concept codes such as NGDP_RPCH (real GDP growth). Default: headline set. |
| `countries` | string or list of strings | none | ISO3/ISO2 codes, exact country names or IMF groups (FAD_G7). Default: WORLD. |
| `start_date` | string | none | Earliest period: YYYY or YYYY-MM-DD. |
| `end_date` | string | none | Latest period: YYYY or YYYY-MM-DD. |
| `include_projections` | boolean | none | Years after 2022 (IMF estimates): true always, false never, default only with end_date. |
| `series_codes` | string or list of strings | none | QDL/ODA codes such as USA_NGDPD. |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |

## ndl_get_bond_index_yields

**Get ICE BofA bond index yields**. Get ICE BofA corporate bond index yields, spreads and returns (ends 2025-02-27). Read-only. Calls Nasdaq Data Link.

Reads QDL/ML (free; Nasdaq no longer updates it): 27 daily ICE BofA index series under their FRED codes from 1996-12-31 (emerging markets 1998-12-31): US investment grade overall and AAA to BBB, US high yield overall and BB to CCC, emerging-market corporates. Yields and option-adjusted spreads are percent; total-return series are index levels. Without `series` and `start_date`, returns the latest value of every series on or before `end_date`, with its label. Rows are newest first.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `series` | string or list of strings | none | ICE BofA series codes, e.g. BAMLH0A0HYM2 (US high-yield spread), BAMLC0A4CBBBEY (BBB yield). Default: all 27. |
| `start_date` | string | none | Earliest date to include, YYYY-MM-DD. |
| `end_date` | string | none | Latest date to include, YYYY-MM-DD. |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |

### Tables

| Table | Name | Free key | Last refreshed by Nasdaq |
|---|---|---|---|
| `QDL/ML` | Corporate bond index yields | Free | 2025-03-02 |
