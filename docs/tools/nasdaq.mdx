## ndl_get_retail_trading_activity

**Get retail trading activity**. Daily retail activity share and net sentiment for US tickers (Nasdaq RTAT). Read-only. Calls Nasdaq Data Link.

rtat10 (NDAQ/RTAT10, free for any key): each trading day's 10 tickers with the largest share of retail dollar volume, from 2016 to the previous trading day. rtat (NDAQ/RTAT): every covered ticker; without an RTAT subscription, only a fixed 7-row sample dated 2016-01-15.

`activity` is the ticker's share (0-1) of the day's retail dollar volume; `sentiment` (-100 to +100) is retail net buying minus selling over 10 trading days. A ticker absent from RTAT10 on a day was outside that day's top 10; notes give each requested ticker's last top-10 day. Newest day first, then by activity; without dates, the most recent days (rtat without tickers: the latest day).

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `tickers` | string or list of strings | none | Optional ticker or list of tickers to restrict the results to. |
| `start_date` | string | none | Earliest date to include, YYYY-MM-DD. |
| `end_date` | string | none | Latest date to include, YYYY-MM-DD. |
| `dataset` | string | `"rtat10"` | rtat10: free daily top 10; rtat: premium full universe. One of: `rtat10`, `rtat`. |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |

## ndl_get_ticker_changes

**Get ticker symbol changes**. US ticker symbol changes and new listings, keyed by FIGI (NDAQ/TC, free, daily). Read-only. Calls Nasdaq Data Link.

A row means the security `figi` traded as `symbol` from `date` on; resolve_history adds the same FIGI's previous_symbol, next_symbol and next_date. Rows dated 1980-01-01 are the baseline symbol, not changes; a FIGI with no earlier row is a new listing. Newest first; without filters, the last 90 days. A ticker matches every FIGI that has used it, so a reused ticker shows each holder (FB: Meta until 2022-06-09, another security since 2025).

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `tickers` | string or list of strings | none | Ticker or list of tickers; each matches every FIGI that has used it. |
| `figis` | string or list of strings | none | FIGIs (12 characters, e.g. 'BBG000MM2P62'): one or a list. |
| `start_date` | string | none | Earliest date to include, YYYY-MM-DD. |
| `end_date` | string | none | Latest date to include, YYYY-MM-DD. |
| `resolve_history` | boolean | `true` | Add previous_symbol, next_symbol and next_date (one extra request). |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |

|---|---|---|---|

## ndl_get_equities360

**Get Equities 360 company data**. Nasdaq Equities 360 company data; needs a paid subscription (no free sample). Read-only. Calls Nasdaq Data Link.

Free-key alternatives: ndl_search_tickers and ndl_get_fundamentals. statistics: market cap, P/E, 52-week range, yield. The five fundamentals datasets: by calendardate and dimension, from 2008. reference_data: exchange, sector, industry. corporate_actions: splits, mergers, dividends. Dates filter calendardate or the action date; dated rows come newest first.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `dataset` | string | required | Table to read. One of: `statistics`, `fundamentals_summary`, `fundamentals_details`, `balance_sheet`, `income_statement`, `cash_flow`, `reference_data`, `corporate_actions`. |
| `tickers` | string or list of strings | none | Tickers or FIGIs (12 characters): one or a list. |
| `dimension` | string | none | Fundamentals only: MRQ quarter, MRY year, MRT trailing 12 months. One of: `MRQ`, `MRY`, `MRT`. |
| `start_date` | string | none | Earliest date to include, YYYY-MM-DD. |
| `end_date` | string | none | Latest date to include, YYYY-MM-DD. |
| `contra_tickers` | string or list of strings | none | corporate_actions only: the other party's ticker, e.g. an acquirer. |
| `columns` | list of strings | none | Columns (default all; fundamentals_details: 27 of 70). ['all'] for every column. |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |
