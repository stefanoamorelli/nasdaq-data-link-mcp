## ndl_search_zillow_regions

**Search Zillow regions**. Find Zillow region ids (state, metro, county, city, ZIP, neighborhood) by name. Read-only. Calls Nasdaq Data Link.

Searches ZILLOW/REGIONS (about 89,000 regions, free) for names that start with the query, ignoring case and punctuation. Exact names rank first, then larger areas. Results carry the region_id that ndl_get_zillow_data takes, the type, the state and the larger areas Zillow lists for the region.

One place often exists at several levels (city, metro, county), each with its own id. Metros have every indicator (home values, rents, inventory and sales), ZIP codes home values and rents, other levels home values only.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `query` | string | required | Start of the region name as Zillow spells it, optionally followed by the state code ('Austin, TX', 'Saint Louis'), or a ZIP code ('78701'). |
| `region_type` | string | none | Only regions of this type. The national series is the metro 'United States'. One of: `state`, `metro`, `county`, `city`, `zip`, `neighborhood`. |
| `limit` | integer (1-100) | `20` | Maximum results. |

### Tables

|---|---|---|---|
| `ZILLOW/REGIONS` | Zillow region list | Free | 2025-07-20 |

## ndl_get_zillow_data

**Get Zillow housing data**. Get Zillow home values, rents, inventory or sales for up to 10 US regions. Read-only. Calls Nasdaq Data Link.

Reads ZILLOW/DATA (free; last updated July 2025): date, region_id, value rows, newest first, and a summary per region. Regions are ids, not names: ndl_search_zillow_regions finds them, and ndl_search_zillow_indicators lists indicator ids and the region types each covers.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `indicator` | string | required | Indicator id ('ZALL' is home values, all homes) or exact name, from ndl_search_zillow_indicators. |
| `regions` | string or list of strings | required | Up to 10 region ids from ndl_search_zillow_regions, e.g. '394355' or ['9', '102001']. |
| `region_type` | string | none | When set, every region id must be of this type. One of: `state`, `metro`, `county`, `city`, `zip`, `neighborhood`. |
| `start_date` | string | none | Earliest date to include, YYYY-MM-DD. |
| `end_date` | string | none | Latest date to include, YYYY-MM-DD. |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |

### Tables

| Table | Name | Free key | Last refreshed by Nasdaq |
|---|---|---|---|
| `ZILLOW/DATA` | Zillow housing series | Free | 2025-07-20 |
| `ZILLOW/REGIONS` | Zillow region list | Free | 2025-07-20 |

## ndl_search_zillow_indicators

**Search Zillow housing indicators**. Search the 56 Zillow indicators by keyword, category or region type. Read-only. Calls Nasdaq Data Link.

Home values (ZHVI: all homes, single-family, condo, top and bottom tier, 1 to 5+ bedrooms), rents (ZORI) and inventory and sales (sale and list prices, for-sale inventory, days to pending, price cuts, monthly and weekly). Reads the free ZILLOW/INDICATORS table, kept for a day; each result lists the region types that have data.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `query` | string | none | Words that must all appear in the id, name or category, e.g. 'condo' or 'sale price weekly'. Without them all are listed. |
| `category` | string | `"all"` | Only indicators in this category. One of: `all`, `home_values`, `rentals`, `inventory_and_sales`. |
| `region_type` | string | none | Only indicators that cover this region type. One of: `state`, `metro`, `county`, `city`, `zip`, `neighborhood`. |

### Tables

| Table | Name | Free key | Last refreshed by Nasdaq |
|---|---|---|---|
| `ZILLOW/INDICATORS` | Zillow indicator list | Free | 2025-07-20 |
