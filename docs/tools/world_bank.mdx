## ndl_search_world_bank_indicators

**Search World Bank indicators**. Find World Bank indicator series_ids by keyword (GDP, inflation, literacy, CO2). Read-only. Calls Nasdaq Data Link.

Ranks the 1,484 World Development Indicators in WB/METADATA (free for any API key) by keyword matches in the name first and the definition second; an exact series_id comes first. The list is downloaded once and reused for 24 hours. The series_id values are the input of ndl_get_world_bank_data.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `query` | string | required | Keywords or a series_id, e.g. 'GDP', 'CO2 emissions per capita', 'NY.GDP.MKTP.CD' or an id prefix like 'SI.POV'. |
| `limit` | integer (1-50) | `10` | Maximum indicators to return. |

## ndl_get_world_bank_data

**Get World Bank indicator data**. Get yearly World Bank indicator values for countries and aggregates (WB/DATA). Read-only. Calls Nasdaq Data Link.

World Development Indicators, free for any API key: 1960-2023 for 217 economies and 48 aggregates (World, regions, income groups, EU, Euro area); some series (poverty, debt) end earlier. Nasdaq refreshed the table in August 2025. IMF projections past 2023: ndl_get_imf_weo_data.

Indicators are series_ids (ndl_search_world_bank_indicators finds them by keyword). Dates filter by year. Rows run newest year first, then in the order given, so `limit` keeps the latest years; `coverage` gives the years with data per pair.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `indicators` | string or list of strings | required | Up to 10 series_ids such as 'NY.GDP.MKTP.CD' (a list or a comma-separated string). |
| `countries` | string or list of strings | required | Up to 30 ISO3/ISO2 codes, World Bank aggregate codes or exact World Bank names ('ITA', 'KR', 'WLD', 'Euro area'). |
| `start_date` | string | none | Earliest period: YYYY or YYYY-MM-DD. |
| `end_date` | string | none | Latest period: YYYY or YYYY-MM-DD. |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |
