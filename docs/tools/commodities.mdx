## ndl_get_cot_report

**CFTC Commitments of Traders report**. Weekly CFTC Commitments of Traders positions for one futures market. Read-only. Calls Nasdaq Data Link.

Reads QDL/FON, QDL/LFON, QDL/FCR or QDL/CITS (per `report`): Tuesday as-of dates, newest first, with longs-minus-shorts `*_net` columns. Free with an API key; ends with the 2026-06-09 report.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `contract` | string | required | 6-character CFTC contract code or exact CFTC market name, e.g. '088691' or 'GOLD'. |
| `report` | string | none | Default: disaggregated (physical commodities) if available, else legacy (all contracts). concentration: top 4/8 traders; index_traders: 13 farm markets. One of: `disaggregated`, `legacy`, `concentration`, `index_traders`. |
| `measure` | string | `"positions"` | changes = week over week. One of: `positions`, `changes`, `percent_of_open_interest`, `trader_counts`. |
| `include_options` | boolean | `false` | Futures and options combined. |
| `crop` | string | `"all"` | Crop-year split (farm markets). One of: `all`, `old`, `other`. |
| `start_date` | string | none | Earliest date to include, YYYY-MM-DD. |
| `end_date` | string | none | Latest date to include, YYYY-MM-DD. |
| `limit` | integer (1-1000) | `52` | Maximum weekly rows. |

### Tables

| Table | Name | Free key | Last refreshed by Nasdaq |

| `QDL/FCR` | CFTC concentration ratios | Free | 2026-06-20 |

## ndl_get_jodi_energy_data

**JODI oil and gas statistics**. Monthly oil and gas production, demand, trade and stocks by country (JODI). Read-only. Calls Nasdaq Data Link.

Reads QDL/JODI: ~100 countries, monthly from 2002, newest first. Over 30 series without dates return the latest month only. Free with an API key; Nasdaq's copy ends at 2024-12.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `countries` | string or list of strings | required | ISO 3166 alpha-3 codes: 'USA' or ['SAU', 'RUS']. |
| `product` | string | none | crude_oil, gasoline, gas_diesel, jet_fuel, natural_gas, oil (all oil products), ... Default: all. |
| `flow` | string | none | production, demand, imports, exports, closing_stocks, ... Default: all. |
| `unit` | string | none | Default kbd (oil stocks: kb), gas mcm. One of: `kbd`, `kb`, `kt`, `kl`, `conversion_factor`, `mcm`, `tj`. |
| `codes` | string or list of strings | none | Raw JODI codes, e.g. 'CRPRKD' (crude production, kb/d). |
| `start_date` | string | none | Earliest date to include, YYYY-MM-DD. |
| `end_date` | string | none | Latest date to include, YYYY-MM-DD. |
| `limit` | integer (1-1000) | `100` | Maximum rows. |

### Tables

## ndl_get_opec_basket_price

## ndl_get_lme_warehouse_stocks

**LME warehouse metal stocks**. Daily LME warehouse stock levels in tonnes by metal and location; no prices. Read-only. Calls Nasdaq Data Link.

Reads QDL/LME, which holds stocks, not prices: opening and closing stock, tonnes delivered in and out, and open (live warrant) versus cancelled tonnage for 9 base metals at 32 LME locations plus their total, from 2015-01-02. Without dates, 1-4 metals return recent history and more return the latest day only. Free with an API key; frozen since 2024-07 (last day 2024-07-30).

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `metals` | string or list of strings | none | Metal names or LME codes: copper (CU), aluminium (PA), aluminium alloy (AA), NASAAC (NA), nickel (NI), lead (PB), zinc (ZI), tin (TN), cobalt (CO), or sub-codes like NIFC. Default: all nine. |
| `location` | string | `"ALL"` | Warehouse location code or city, e.g. 'NRO' or 'Rotterdam'. Default 'ALL', the sum of every location. |
| `breakdown` | boolean | `false` | Add each metal's sub-category codes, which sum to it. |
| `start_date` | string | none | Earliest date to include, YYYY-MM-DD. |
| `end_date` | string | none | Latest date to include, YYYY-MM-DD. |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |

### Tables

| Table | Name | Free key | Last refreshed by Nasdaq |
|---|---|---|---|
| `QDL/LME` | Metal warehouse stocks (LME) | Free | 2024-08-01 |

## ndl_get_wasde_data

**USDA WASDE supply and demand**. USDA World Agricultural Supply and Demand Estimates (WASDE) report tables. Read-only. Calls Nasdaq Data Link.

Reads tables of one report from WASDE/DATA, with their names from WASDE/METADATA (45 tables per report covering grains, oilseeds, cotton, sugar, livestock, dairy): supply and use items by region, marketing year and estimate month. Projection years show the prior and current month's estimates as separate `period` rows.

Free with an API key. Monthly reports from 2010-08; Nasdaq stopped at the 2024-02 report.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `query` | string | required | WASDE table code(s) of the report, up to 3 comma-separated, e.g. 'CORN_US_12'; an unknown code returns the matching codes. |
| `report_month` | string | none | Report month YYYY-MM, 2010-08 to 2024-02 with gaps (default: the latest). |
| `region` | string | none | Region name as written in the table, e.g. 'United States' or 'World'; US, UK and EU work too. |
| `item` | string | none | Item name as written in the table, e.g. 'Ending Stocks' or 'Production'. |
| `limit` | integer (1-1000) | `1000` | Maximum rows to return (default 1000). |

### Tables

| Table | Name | Free key | Last refreshed by Nasdaq |
|---|---|---|---|
| `WASDE/DATA` | USDA supply and demand estimates | Free | 2024-02-14 |
| `WASDE/METADATA` | USDA WASDE report tables | Free | 2024-02-14 |
