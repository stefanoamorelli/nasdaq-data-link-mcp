## ndl_search_tables

**Search Nasdaq Data Link tables**. Search a bundled list of Nasdaq Data Link tables by keyword. Read-only. Answers locally, without calling Nasdaq.

Nasdaq Data Link has no search API. The list covers the tables this server's tools read plus every table a free key reads in full, each with a short description and what a free key gets. ndl_describe_table and ndl_query_table also accept any VENDOR/TABLE code that is not listed.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `query` | string | `""` | Keywords, a vendor or a table code, e.g. 'retail sentiment', 'fundamentals', 'SHARADAR', 'WB/DATA'. Empty lists every table. |
| `access` | string | `"all"` | Only tables a free key can read fully ('free'), as a sample ('sample') or not at all ('subscription'). One of: `all`, `free`, `sample`, `subscription`. |
| `vendor` | string | none | Restrict to one vendor code, e.g. 'NDAQ', 'SHARADAR', 'QDL'. |
| `limit` | integer (1-100) | `20` | Maximum results. |

## ndl_describe_table

**Describe a table**. Show a table's columns, filterable columns, primary key and freshness. Read-only. Calls Nasdaq Data Link.

Reads the live metadata endpoint, which works even for premium tables your key cannot read, and adds what a free key gets when the table is in the bundled list.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `table_code` | string | required | Table code as VENDOR/TABLE, e.g. 'NDAQ/RTAT10' or 'WB/DATA'. |

## ndl_query_table

**Query a table**. Read rows from any Nasdaq Data Link table, with filters and paging. Read-only. Calls Nasdaq Data Link.

Filters only work on a table's filterable columns (see ndl_describe_table). Premium tables return a fixed sample to free keys. Results are capped by `limit`; follow `next_cursor` for more pages.

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `table_code` | string | required | Table code as VENDOR/TABLE, e.g. 'NDAQ/RTAT10' or 'WB/DATA'. |
| `filters` | object | none | Row filters on the table's filterable columns. Equality: \{'ticker': 'AAPL'\}; any of several values: \{'ticker': ['AAPL', 'MSFT']\}; ranges with gt/gte/lt/lte: \{'date.gte': '2024-01-01', 'date.lte': '2024-03-31'\} or \{'date': \{'gte': '2024-01-01'\}\}. Dates are YYYY-MM-DD. |
| `columns` | list of strings | none | Columns to return (default: all). Fewer columns, smaller output. |
| `limit` | integer (1-1000) | none | Maximum rows to return (default 100, max 1000). |
| `cursor` | string | none | `next_cursor` from a previous call, to read the next page. |
| `sort_by` | string | none | Column to sort by, locally (Nasdaq returns rows unsorted). Reads up to 10,000 matching rows first; cannot be combined with cursor. |
| `descending` | boolean | `false` | Sort in descending order. |

## ndl_export_table

**Export a table as CSV**. Request a full (filtered) table export as a zipped CSV download link. Read-only. Calls Nasdaq Data Link.

For data too large to read through ndl_query_table. Returns a link that expires after 30 minutes; nothing is downloaded by the server. Nasdaq limits exports to a few per hour per key and applies the same entitlements as queries (free keys get sample-sized files for premium tables).

### Parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `table_code` | string | required | Table code as VENDOR/TABLE, e.g. 'NDAQ/RTAT10' or 'WB/DATA'. |
| `filters` | object | none | Row filters on the table's filterable columns. Equality: \{'ticker': 'AAPL'\}; any of several values: \{'ticker': ['AAPL', 'MSFT']\}; ranges with gt/gte/lt/lte: \{'date.gte': '2024-01-01', 'date.lte': '2024-03-31'\} or \{'date': \{'gte': '2024-01-01'\}\}. Dates are YYYY-MM-DD. |
| `columns` | list of strings | none | Columns to return (default: all). Fewer columns, smaller output. |
| `wait_seconds` | integer (0-60) | `15` | How long to wait for Nasdaq to finish building the file. |

## ndl_check_api_status

**Check API key and quota**. Check the API key, the remaining daily call quota and the enabled toolsets. Read-only. Calls Nasdaq Data Link.

Makes one small request to a free table. Useful when other tools fail with authentication or rate-limit errors.

### Parameters

None.
